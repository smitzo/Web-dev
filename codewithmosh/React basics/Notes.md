### Additional Info to Enhance Your Notes:

* **Why use PascalCase?**
  PascalCase helps React differentiate between built-in HTML tags (like `<div>`) and user-defined components (`<Message />`).

* **Why Babel?**
  Babel supports other ES6+ JavaScript features alongside JSX, ensuring compatibility across browsers.

* **Using `ReactDOM.createRoot`**
  This method is new in React 18+, allowing concurrent features and better rendering performance.
